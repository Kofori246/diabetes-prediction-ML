# Diabetes Prediction Using Machine Learning

This project builds a Random Forest classifier to predict whether a patient is likely to have diabetes based on diagnostic measurements. It is an independent portfolio project designed to demonstrate my skills in data analysis, machine learning, and Python programming.

## 🔍 Project Overview
The goal is to classify patients as diabetic or non-diabetic using clinical features such as:
- Glucose level
- BMI
- Age
- Blood pressure
- Insulin
- Skin thickness
- Pregnancies

## 🧠 Model Used
- Random Forest Classifier
